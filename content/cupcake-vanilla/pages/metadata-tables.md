Title: Metadata tables
Order: 02
Summary: Finding, creating, validating, exporting and deleting metadata tables.
Screens: metadata-tables

**Metadata Tables** lists the tables you can open: your own, those of your lab groups and, with **Show Shared
Tables**, those shared with you.

![](shot:gui-vanilla/vanilla-tables)

## Finding a table

**Search & Filters** narrows the list by name, lab group, status (published or draft) and locked tables. **Column
Content** finds tables by a column name or value, of any type or only characteristics, factor values or comments;
**Exact match** matches the whole value. Staff see every table with **Admin View (All Tables)**.

## Creating a table

1. Choose **New Table**.

    ![](shot:steps-vanilla/table-01-list)

2. Enter the table's name and its number of samples, from 1 to 10,000. Optionally describe it, give it a version and
   assign it to a lab group; a table without a lab group is personal.

    ![](shot:steps-vanilla/table-02-new-table)

3. Save. The table appears in the list.

    ![](shot:steps-vanilla/table-03-created)

**Use Template** creates a table from a table template instead, with its columns already set up; see
[Templates]({filename}templates.md).

## Working with tables

Each row's actions **View**, **Edit**, **Validate**, **Export** and **Delete** the table. Locked tables are marked and
cannot be changed.

Select several tables to export them together with **Bulk Export SDRF** or **Bulk Export Excel**.
